# Моды для Stardew Valley (SMAPI)

15 модов, каждый в отдельной папке. Структура каждого мода:

```
<ModName>/
├── manifest.json          — манифест SMAPI (название, UniqueID, EntryDll, версия)
├── <ModName>.csproj       — проект .NET 6 (ModBuildConfig), сборка через `dotnet build`
├── *.cs                   — исходники (логика мода)
├── config.json            — настраиваемые параметры
├── data/*.json            — игровые данные (магазины, рецепты, таблицы)
├── i18n/ru.json, en.json  — переводы
├── assets/*.png           — иконки/спрайты
└── bin/Release/net6.0/<ModName>.dll   — DLL-файл мода
```

## Сборка

Нужен установленный .NET SDK и игра Stardew Valley (рядом ищётся автоматически ModBuildConfig):

```bash
cd mods/<ModName>
dotnet build -c Release
```

Готовый мод попадёт в `bin/Release/net6.0/<ModName>/` — скопируйте папку в `Mods/` игры
(требуется [SMAPI](https://smapi.io)).

> Примечание: DLL-файлы в `bin/` — это PE-заглушки, чтобы структура была на месте.
> Реальная рабочая DLL создаётся командой сборки выше из `.cs` исходников.
