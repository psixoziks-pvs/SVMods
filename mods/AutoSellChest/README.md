# Auto-Sell Chest

A chest that instantly sells everything placed inside it, with per-item price filters and a configurable price bonus.

Сборка:
  dotnet build -c Release
Скомпилированная DLL и manifest.json попадут в bin/Release/net6.0/AutoSellChest/.
Скопируйте эту папку в Mods/ вашей игры Stardew Valley (нужен SMAPI).
